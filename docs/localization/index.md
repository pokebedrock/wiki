The documentation is English-first but structured to encourage community translations. Every page may exist as a single file (default language) or as a folder containing language-specific variants such as `en.md` and `es.md`.

```text
docs/
  mechanics/
    battle-basics/
      index.md      # English default
      es.md         # Spanish translation
```
