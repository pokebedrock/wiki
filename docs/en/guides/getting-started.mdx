## Prerequisites

- Node.js 20.0.0 or newer (matches the `"engines"` field in `package.json`)
- npm 10.x (bundled with Node 20)

Verify your versions:

<ShellBlock command="node --version\nnpm --version" />

If you use `nvm`, install and activate the right runtime before running any repo commands:

<ShellBlock command="nvm install 20\nnvm use 20" />

## 1. Clone & Install

<ShellBlock command="git clone git@github.com:pokebedrock/wiki.git\ncd wiki\nnpm ci" />

## 2. Create a Branch

<ShellBlock command="git checkout -b docs/my-topic" />


## 3. Author Content

- Pick a category under `docs/`.
- Copy the frontmatter template from `CONTRIBUTING.md`.
- Add assets relative to the document path (for example,
  `../../assets/images/ui.webp`).

Use MDX if you need components, otherwise stick to Markdown for readability.

## 4. Validate

<ShellBlock command="npm run ci" />

## 5. Open a PR

Fill out the PR template, link related issues, and request a review from `@pokebedrock/wiki-maintainers`.
