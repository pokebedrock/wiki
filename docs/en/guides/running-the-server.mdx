## Install Dependencies

<ShellBlock command="npm ci" />

## Run Linting

<ShellBlock command="npm run ci" />

The CI task runs markdown, frontmatter, image validation, link checks, and generated
search/manifests drift checks in one pass. Re-run it after editing files; there's no
watch flag wired up for the current tooling stack.

## Preview

This repo does not ship a dedicated docs dev server. For day-to-day doc work:

- Use your editor's Markdown/MDX preview (VS Code, Obsidian, etc.) to check prose,
  headings, and callout rendering.
- Run `npm run build:search` when you want to regenerate the tracked search payloads
  and frontend manifests after larger content edits.
- Use the website frontend repo for full-site rendering checks; follow whatever wiki-path
  override that repo currently documents instead of assuming this repo exposes its own
  preview app.
