| Term | Description | Notes |
| --- | --- | --- |
| PokéCoins | In-game premium currency | Keep untranslated |
| Survival Pass | Seasonal rewards track | Use localized equivalent when the game provides one |
| search index | Generated search payload consumed locally or synced remotely | Prefer a consistent noun phrase instead of alternating between `index`, `payload`, and `search data` in the same page |
| frontend manifest | Generated JSON manifest used by the website frontend for Pokemon, moves, and move learners | Translate `manifest` naturally, but keep the frontend/backend distinction explicit |
| move learner | Pokemon entry listed as able to learn a move | Keep this distinct from the move itself and from broader learnset terminology |
| website backend | Protected backend service that receives synced wiki search payloads | Keep this distinct from the wiki repo and the public frontend |
| Content Request | GitHub issue template for requesting new pages or localization work | Keep the template name capitalized when referencing the repo form |

Add more rows as localization efforts expand, especially when repeated automation terms start appearing across multiple localized pages.
