## Required software

```bash
npm install --global markdownlint-cli@0.41.0
npm install --global lychee@0.15.1
```

- Install Node.js 20 LTS
- Configure your editor with the Markdownlint extension
- Enable MDX syntax highlighting

## Recommended VS Code extensions
