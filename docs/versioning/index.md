Documentation follows semantic versioning aligned with the PokéBedrock release cadence:

- Major versions introduce structural changes or new game systems
- Minor versions add incremental features and guides
- Patch versions fix typos, clarify steps, or update screenshots

Each release should snapshot the `docs/` directory and update the changelog.
