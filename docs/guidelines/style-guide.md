- Use sentence case for headings: `### Battle prep` instead of `### Battle Prep`
- Keep paragraphs under 120 characters per line for readability in diffs
- Favor ordered lists for sequential steps and unordered lists otherwise
- Prefer inline code for filenames and commands (`docs/_meta.json`)
- Capitalize Pokémon names and items according to the in-game spelling
- Embed admonitions using `:::note`, `:::tip`, or `:::warning`
