## Formatos

- Preferir `webp` para imagenes raster y `svg` para arte vectorial.
- Convertir cargas PNG/JPEG usando ImageMagick o Squoosh antes de hacer commit.
- Guardar archivos fuente de diagramas (`.drawio`, `.excalidraw`) en `assets/diagrams`.

## Limites de tamano

- Imagenes inline <= 600 KB (aplicado por `npm run lint:images`).
- Diagramas <= 5 MB; cualquier cosa mayor debe usar Git LFS.

## Alt text y captions

- Proveer alt text descriptivo que transmita la misma informacion que la imagen.
- Usar captions debajo de diagramas complejos para agregar contexto.

## Checklist de revision

- [ ] Archivo guardado bajo `assets/`
- [ ] Alt text completado
- [ ] Formato `webp` o `svg`
- [ ] Tamano ≤ 600 KB (inline)
- [ ] Referenciado con una ruta relativa en la documentacion
