## Formatos

- Preferir `webp` para imágenes ráster y `svg` para arte vectorial.
- Convertir cargas PNG/JPEG usando ImageMagick o Squoosh antes de hacer commit.
- Guardar archivos fuente de diagramas (`.drawio`, `.excalidraw`) en `assets/diagrams`.

## Límites de tamaño

- Imágenes inline ≤ 600 KB (aplicado por `npm run lint:images`).
- Diagramas ≤ 5 MB; cualquier archivo mayor debe usar Git LFS.

## Texto alternativo y captions

- Proveer texto alternativo descriptivo que transmita la misma información que la imagen.
- Usar captions debajo de diagramas complejos para agregar contexto.
