## Formatos

- Prefiere `webp` para imágenes ráster y `svg` para arte vectorial.
- Convierte los PNG/JPEG con ImageMagick o Squoosh antes de hacer commit.
- Guarda los archivos fuente de diagramas (`.drawio`, `.excalidraw`) en `assets/diagrams`.

## Límites de tamaño

- Imágenes inline ≤ 600 KB (validado por `npm run lint:images`).
- Diagramas ≤ 5 MB; si son más grandes deben versionarse con Git LFS.

## Texto alternativo y pies de foto

- Proporciona texto alternativo descriptivo que comunique lo mismo que la imagen.
- Añade un pie de foto debajo de diagramas complejos para aportar contexto.

## Git LFS

Versiona los binarios grandes:

- [ ] Formato `webp` o `svg`
- [ ] Tamaño ≤ 600 KB (inline)
