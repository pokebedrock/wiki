| Termino | Descripcion | Notas |
| --- | --- | --- |
| PokéCoins | Moneda premium del juego | Mantener sin traducir |
| Survival Pass | Pase de recompensas de temporada | Usar equivalente localizado cuando el juego lo provea |
| search index | Payload de busqueda para uso local o sync remota | No alternar entre `indice`, `payload` y `datos de busqueda` en la misma pagina |
| frontend manifest | Manifest JSON generado que usa el frontend del sitio para Pokemon, moves y move learners | Traducir `manifest` de forma natural, pero dejando explicita la diferencia entre frontend y backend |
| move learner | Entrada de Pokemon que puede aprender un movimiento | Mantenerlo separado del movimiento en si y de terminos mas amplios como learnset |
| website backend | Servicio backend protegido que recibe payloads de busqueda sincronizados desde la wiki | Mantenerlo separado del repo de la wiki y del frontend publico |
| Content Request | Plantilla de issue de GitHub para pedir paginas nuevas o trabajo de localizacion | Mantener el nombre de la plantilla en mayusculas cuando se refiera al formulario del repo |

Agregar mas filas a medida que crezcan los esfuerzos de localizacion.
Priorizar terminos de automatizacion que se repitan en varias paginas traducidas.
