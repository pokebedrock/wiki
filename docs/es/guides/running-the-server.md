## Requisitos

- Node.js 20+
- npm 10+

## Pasos

1. `npm ci`
2. Edita los archivos en `docs/`.
3. Ejecuta `npm run ci`.
4. Abre un PR y añade la etiqueta `language:es`.

## Revisión

Marca el estado como `beta` hasta que otra persona revise la traducción.
