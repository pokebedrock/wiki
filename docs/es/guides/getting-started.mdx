## 1. Clonar e instalar

<ShellBlock command="git clone git@github.com:pokebedrock/wiki.git\ncd wiki\nnpm ci" />

## 2. Crear una rama

<ShellBlock command="git checkout -b docs/my-topic" />


## 3. Crear contenido

- Elegi una categoria bajo `docs/`.
- Copia la plantilla de frontmatter desde `CONTRIBUTING.md`.
- Agrega assets con ruta relativa al documento (por ejemplo,
  `../../assets/images/ui.webp`).

Usa MDX si necesitas componentes; en caso contrario, usa Markdown por legibilidad.

## 4. Validar

<ShellBlock command="npm run ci" />

## 5. Abrir una PR

Completa la plantilla de PR, enlaza issues relacionados y solicita revision a `@pokebedrock/wiki-maintainers`.
