# PokéBedrock Wiki Repository

This repository powers the PokéBedrock documentation site. It stores content, assets, and automation workflows that keep the wiki consistent and ready to sync with the live website.

## Highlights

- Markdown-first authoring with optional MDX for rich components
- Frontmatter schema validation, markdown linting, and link checking enforced via CI
- Localization-ready file structure with reusable snippets and partials
- GitHub Actions for publishing hooks, search indexing, and quality checks

Refer to `PLAN.md` for the long-term roadmap and open tasks.
